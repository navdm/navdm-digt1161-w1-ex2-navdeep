# Bug Report

## Title
Login button does not respond when valid credentials are entered

## Description
The login button does not respond after valid username and password credentials are entered.

## Steps to Reproduce
1. Open the application login page.
2. Enter a valid username.
3. Enter a valid password.
4. Click the **Login** button.

## Expected Behavior
The user should be successfully logged in and redirected to the main application page.

## Actual Behavior
Nothing happens after clicking the **Login** button.

## Severity
Medium

## Environment
- OS: Windows 11
- Browser: Google Chrome
- Version: Latest

## Additional Notes
The issue appears to occur consistently when using the Chrome browser.
